## Content Type

The `Content-Type` header indicates the format of the data being sent or received in an HTTP request or response.

### Most Commonly Used Content Types

When working with web applications and REST APIs, the following content types are the most frequently used:

```text
text/plain
text/html
application/json
multipart/form-data
application/x-www-form-urlencoded
image/jpeg
image/png
application/pdf
```
